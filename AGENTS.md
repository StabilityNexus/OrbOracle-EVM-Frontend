# Orb Oracle EVM Frontend Agent Guidelines

This repository contains the Next.js frontend code for the Orb Oracle protocol. Refer to this file for compilation, commands, style conventions, and architecture constraints.

---

## Tech Stack
- **Framework:** Next.js 14+ (React App Router)
- **Styling:** Tailwind CSS v4, shadcn/ui
- **Web3 Integration:** Wagmi, Viem, RainbowKit

---

## Commands
- **Development Server:** `npm run dev`
- **Production Build:** `npm run build`
- **Lint Check:** `npm run lint`
- **Type Check:** `npx tsc --noEmit`

---

## Architecture & Code Style

### 1. Next.js App Router Structure
- All pages and routes must follow Next.js App Router layouts (e.g. `app/[oracleId]/page.tsx`).
- Components should be modular and located inside the `components/` folder.

### 2. Styling Standards
- Use Tailwind classes for all component-level styles.
- Design tokens (colors, borders, spacing) must map to the CSS variables in `styles/globals.css` using modern OKLCH formatting.

### 3. TypeScript Strictness
- Enforce type safety across all React components, Wagmi hooks, and page parameters.
- Avoid using `any`. Define props interfaces explicitly.

### 4. Custom Wagmi Integration
- All on-chain interactions should use custom hooks or helper functions to cleanly separate contract reads/writes from UI presentation logic.

---

## Boundaries
- **Dependencies:** Never modify files under `node_modules/` or next config base setups.
- **Autogenerated files:** Never modify build artifacts under `.next/` or `out/`.
- **Environment:** Do not commit `.env` or any file containing private keys, mnemonic phrases, or RPC credentials.

---

## Git Workflow
- **Commit Format:** Follow the **Chris Beams Git Commit Message** guide (imperative subject, capitalized, under 50 characters, wrapped body).
- **Branch Format:** `feat/short-desc`, `fix/short-desc`, or `refactor/short-desc`.
